# Сканер стратегии «продолжение движения дня по рынку»

## Приложение для Windows
**MoexScanner.exe** — окно с вкладками:
- **Автоторговля** — кнопки «Старт» и «Стоп». Поиск формаций идёт постоянно с открытия программы — по будням с 07:00 до закрытия основной сессии (18:40). «Старт торговли» включает сделки на демо-счёте песочницы (входы 10:00–18:00, позиции закрыты к 18:30), «Стоп торговли» — только наблюдение и уведомления;
- **Сегодня** — сигналы в 15:00 для ручной торговли;
- **Журнал форвард-теста** — итоги каждого дня по стратегии «15:00»;
- **Настройки** — порог, время входа, капитал, токен, параметры стратегии «всплеск объёма + откат к EMA20».

### Что делает робот
1. **Индекс.** С 10:00 каждую минуту считает движение всех акций индекса от открытия и среднее движение рынка.
2. **Стратегия «15:00»** (проверена на истории): во время входа открывает сделки по акциям, ушедшим от открытия на порог и больше в сторону рынка; стоп 3%, выход 16:59:50.
3. **Всплеск объёма + откат к EMA20** (15 мин и 1 час по умолчанию, 5 мин включается в настройках; по всем акциям биржи):
   импульс на объёме — одна или серия свечей подряд (на 15 мин до 4 свечей, движение от 3%), оборот в несколько раз выше обычного → свеча касается EMA20 → следующая свеча отскакивает (подтверждение) → вход.
   Стоп — под самой низкой точкой всего отката (включая «закругление» под EMA20) с небольшим запасом. Тейк 1 — половина пути от входа до хая импульса: закрывается 50% позиции, стоп сразу в безубыток, включается трейлинг-стоп. Тейк 2 — хай импульса: закрывается 50% остатка. Остальное ведёт трейлинг-стоп.
   Шорт — зеркально и только при падающем индексе. Выход не позже 18:25. Размер сделки — заданный в настройках % от текущей стоимости портфеля (по умолчанию 10%), до 5 позиций.
   На истории акций индекса результат около нуля (см. «Настройки»), поэтому сделки по ней пишутся в отдельный журнал `sandbox_spikes.csv`.

Дополнительно:
- **Звук** при каждом входе и выходе (включается в «Настройках»).
- **Ручное закрытие**: кнопки «Закрыть выбранную» и «Закрыть все» на вкладке «Автоторговля».
- **График**: двойной щелчок по бумаге в любой таблице или кнопка «Открыть график…» — свечи, объём, EMA10 и EMA20, таймфреймы 1м/5м/15м/1ч/день, линии входа, стопа и тейков открытой позиции.
- **Чем торговать** (Настройки → формация): все российские акции, голубые фишки, акции индекса Мосбиржи, третий эшелон, валюты и металлы, индексы и товары (фьючерсы), все фьючерсы — можно отметить несколько групп. Фильтр по индексу действует только для акций; размер позиции во фьючерсах считается по гарантийному обеспечению.
- **Т-Инвестиции**: кнопки «В Т-Инвестиции», «Терминал Т-Инвестиций», меню по правой кнопке мыши на бумаге и ссылка в сообщениях Telegram открывают страницу инструмента или веб-терминал в браузере.
- **Формации из истории на графике**: ▲/▼ — вход, кружки — выходы (тейк1, тейк2, б/у, трейлинг, стоп) с итогом сделки; при наведении на вход — подробности.
- **Telegram**: вкладка «Telegram» — бот от @BotFather, кнопка «Узнать chat id»; приходят найденные формации (с ценой, стопом и тейками) и сделки робота.

Открытые позиции хранятся в `auto_state.json`: после перезапуска программы и «Старт» робот продолжит их вести. Компьютер не должен засыпать.

### Где взять .exe
- **GitHub:** при каждом обновлении репозитория GitHub Actions собирает `MoexScanner-windows.zip` и выкладывает его в релиз **latest** — вкладка **Releases** или прямая ссылка `releases/latest`.
- **Локально:** запустите `Собрать exe локально.bat` (нужен Python 3.10+), файл появится в `dist\MoexScanner.exe`.
- **Без сборки:** `Запуск без сборки.bat` запускает приложение через установленный Python.

**Сертификаты.** Серверы Т-Инвестиций подписаны российским удостоверяющим центром (НУЦ Минцифры), которого нет в Windows. При первой ошибке сертификата программа сама скачивает эти сертификаты с сервера госуслуг в свою папку `certs` и повторяет запрос. В хранилище Windows ничего не устанавливается: удалите папку программы — и сертификатов нет. Если соединение всё равно не проходит, его подменяет антивирус: добавьте MoexScanner.exe в исключения проверки защищённых соединений.

Windows может предупредить о неизвестном издателе (программа не подписана): «Подробнее» → «Выполнить в любом случае».

## Сервер (круглосуточно) и приложение для Андроида

Робот может работать на арендованном сервере (VPS) круглосуточно, а управлять им можно с телефона.

1. Арендуйте VPS: Ubuntu 22.04 или 24.04, 1 ядро, 1–2 ГБ памяти (Timeweb Cloud, Selectel, REG.RU и т. п., около 300–600 ₽ в месяц).
   Провайдер пришлёт IP-адрес и пароль пользователя root.
2. В программе на Windows откройте вкладку «Сервер и телефон», введите IP и пароль, нажмите «Установить / обновить сервер».
   Программа сама поставит робота на сервер (служба systemd, перезапускается после сбоев и перезагрузки) и перенесёт туда
   токен песочницы, настройки, Telegram, открытые позиции и журналы. Робот на компьютере после этого только наблюдает.
3. Установите на телефон `MoexRobot-android.apk` (из той же сборки; в Андроиде разрешите установку из этого источника)
   и отсканируйте QR-код, который покажет программа.

В приложении: статус и кнопка «Старт/Стоп», открытые позиции с кнопкой «Закрыть», формации, график с EMA10/EMA20 и
сделками робота на истории, закрытые сделки и журнал, все настройки. Звук и уведомление при входе/выходе — пока приложение
открыто; круглосуточно уведомления приходят в Telegram с сервера.

Безопасность: сервер подписан собственным сертификатом, приложение доверяет ему только по отпечатку из QR-кода; каждый запрос
подписан ключом из того же кода. Ни в Windows, ни в телефон, ни в систему сервера сертификаты не устанавливаются
(сертификаты Минцифры для Т-Инвестиций лежат только в папке программы /opt/moexrobot/certs).
Обновление сервера — той же кнопкой «Установить / обновить сервер» (данные и код подключения сохраняются).

## Командная строка
Всё то же доступно без окна через `scanner.py` (см. ниже).

## Правила
- Будни, основная сессия, акции индекса Мосбиржи.
- В 15:00 по Москве для каждой акции считается изменение от цены открытия в 10:00.
- Сигнал: изменение 2% или больше вверх или вниз.
- Фильтр рынка: среднее изменение всех акций индекса к 15:00 в ту же сторону. Иначе сделки нет.
- Вход сразу по направлению движения, стоп 3% от цены входа, выход в 17:00.
- Капитал делится поровну между сигналами дня.

## Установка
1. Установите Python 3.10+ с python.org (при установке отметьте «Add Python to PATH»).
2. В папке со сканером выполните:
   ```
   pip install requests
   ```

## Режим 1. Форвард-тест без токена и без риска (начните с него)
Каждый будний день после 17:15:
```
python scanner.py journal
```
Скрипт загрузит минутки с сайта Мосбиржи, посчитает сигналы и результат дня по правилам стратегии и допишет их в `forward_journal.csv` и `forward_days.csv`. Статистика:
```
python scanner.py stats
```
Пропущенные дни можно дозаполнить:
```
python scanner.py journal --from 2026-10-28 --to 2026-11-15
```
Чтобы запускалось само, создайте задачу в «Планировщике заданий» Windows: ежедневно по будням в 17:20, программа `python`, аргументы `scanner.py journal`, рабочая папка — папка сканера.

## Режим 2. Сигналы в 15:00 для ручной торговли
```
python scanner.py signals
```
Скрипт дождётся 15:00, выведет бумаги, направление и цену стопа. Без токена Т-Инвестиций данные берутся с сайта Мосбиржи, а бесплатные данные там обычно идут с задержкой около 15 минут, поэтому для этого режима лучше задать токен (см. ниже).

## Режим 3. Песочница Т-Инвестиций
1. Получите токен песочницы в настройках Т-Инвестиций (раздел про API, токен для песочницы).
2. Задайте его в переменной окружения, не вставляя никуда больше:
   ```
   setx TINVEST_TOKEN "ваш_токен"
   ```
   Закройте и снова откройте окно командной строки.
3. Проверьте доступ:
   ```
   python scanner.py check --sandbox-token
   ```
4. Запуск в торговый день до 15:00:
   ```
   python scanner.py sandbox --capital 1000000
   ```
   Скрипт сам пополнит демо-счёт, в 15:00 откроет позиции, будет следить за стопом и закроет всё в 17:00. Сделки пишутся в `sandbox_trades.csv`. Окно и компьютер должны работать до 17:00.

## Порог 2,5% (рекомендуется вести параллельно)
Ключ `--threshold 2.5` у `journal`, `stats`, `signals` и `sandbox` (свой отдельный журнал). На истории: около 590 сделок за период вместо 990, в среднем +0,22% на сделку после затрат вместо +0,16%, итог +35% против +24%, обе части истории в плюсе. Удобно вести оба журнала и через 2–3 месяца сравнить.
```
python scanner.py journal --threshold 2.5
```

## Как снизить затраты
Результат сильно зависит от затрат. Входите и выходите лимитными заявками по последней цене вместо рыночных и проверьте свой тариф: при затратах 0,10% на сделку вместо 0,16% итог на истории растёт с +24% до +40%.

## Вариант со входом в 14:30
Ключ `--entry 14:30` у `journal`, `stats`, `signals` и `sandbox` (свой отдельный журнал). На истории он заметно слабее основного: в среднем +0,05% на сделку против +0,16%. Используйте его только для сравнения.

## Чего ждать
По бэктесту за октябрь 2025 – октябрь 2026: в среднем +0,16% на сделку после затрат 0,16%, около половины сделок в плюсе, сигналы примерно в 3 днях из 4, в среднем 5 сделок в такой день, просадка до 7%. Чтобы отличить работающую стратегию от случайности, нужно хотя бы два-три месяца форвард-теста.
